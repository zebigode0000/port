meus projetos

Site de Tatuagem

Landing page responsiva desenvolvida para um estúdio de tatuagem, apresentando serviços, informações do estúdio, galeria de trabalhos e contato. O foco foi criar uma experiência visual moderna e profissional.

Site de Clinica Dentista

Landing page responsiva para um consultório odontológico, destacando serviços, especialidades e formas de contato. O design foi pensado para transmitir confiança e clareza ao usuário.

Lista de Tarefas

Aplicação web simples para gerenciamento de tarefas, permitindo adicionar, concluir e remover atividades. O projeto demonstra lógica em JavaScript e interação com o usuário.

Site para Marmoraria

Site institucional desenvolvido para uma marmoraria, com foco na apresentação de serviços, materiais e informações de contato. O projeto utiliza HTML, Tailwind e JavaScript, com layout responsivo e atenção à experiência do usuário.

Game em JavaScript

Jogo desenvolvido em JavaScript para praticar lógica de programação, manipulação do DOM e eventos. O projeto envolve interação do usuário, regras de jogo e atualização dinâmica da interface.
